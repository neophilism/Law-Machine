# Security

Report suspected vulnerabilities privately to the repository owner through a private channel already available to you. Do not publish exploit details, credentials, private drafts or personal claim information in a public issue. No private reporting endpoint is claimed configured by this foundation.

Agents follow `AGENTS.md`, `security/THREAT_MODEL.md` and `security/E2EESA_ADOPTION.md`. Fix concrete findings and add regression evidence. Independent human review is deferred; implementation and testing continue under the owner's policy. This repository does not claim certification.
