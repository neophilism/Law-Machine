# LM-005 accessible design primitives — review and acceptance evidence

Implements the independently dependency-ready design-system unit over LM-002. Includes text-bearing statuses, reusable buttons/tabs/dialogs/source inspector, loading/error/disabled states, a simplified institution/document illustration, responsive civic styling, a public hypothetical preview and a homepage route to discover it.

Security/privacy review: browser-only visual components, no database or provider import, no credential access, no external links in imported source material, no tracking, no user data or filings. The dialog uses the browser's native focus containment/escape rather than custom global keyboard listeners. A source-inspector preview is explicitly "Not verified"; no legal source text is invented.

Tests committed: \`tests/browser/design.spec.ts\` covers ArrowRight/End navigation, selected tab visibility, focus restoration after Escape, Axe accessibility in desktop/modal and phone views, reduced motion, absent horizontal overflow and disabled simulation. CI also runs workspace lint/type/unit/build/audit and foundation checks. The exact current PR head must pass both named checks before merge; independent human audit is later follow-up, not claimed as performed.

No schema, storage or deployed service is changed; rollback is to revert the design-system PR. CI pass means tested interaction behavior, not certification of the full application or completed legal simulation.
