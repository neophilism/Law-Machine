# LM-011: source-preserving PDF extraction, OCR boundary and review evidence

This is a conservative provider-free subset for unencrypted, traditional-object PDFs. It preserves exact original bytes and source digest, extracts text from bounded uncompressed and FlateDecode page content streams, retains page/object-number anchors, and explicitly labels all extraction as unverified until human/editorial correction. It does not infer real-world legal deadlines or operative rules from OCR/PDF text.

Source security review: archive is never executed or rendered as HTML. Parser enforces input size <=6 MB, decompressed stream <=4 MB, <=150 pages, <=10,000 objects, <=20 content references/page and <=20,000 text blocks/stream; rejects invalid header/EOF, duplicate object IDs, encrypted PDFs, unsupported compression and malformed references. Byte decoding is conservative, and unidentified CMaps/hex strings are flagged instead of silently claiming accurate typography.

Quality diagnostics: image-only/scanned or unextractable pages, possible multi-column text layout and unverified page order are explicit; page/object anchors are retained. Multi-column sequence is NOT rearranged authoritatively. The platform can still present preserved PDF bytes for viewing and page-specific correction even when OCR is absent. The isolated OCR port requires an explicit injected sandboxed implementation; its results always require editorial correction and can never silently become operative law. A reviewed correction retains the source digest and the reviewer's identity separately from original bytes.

Testing: toy renderable conventional PDF fixtures generated with consistent xref offsets in unit tests, both compressed and uncompressed text operators, page transitions, image-only and column-like layouts, malformed/encrypted/unsupported input, explicit review and opt-in OCR. No API credentials, storage, migrations or deployment. Exact-head required checks: foundation + workspace, including pnpm check/audit/build and browser tests.

Scope limits: advanced object streams, full font CMaps, signed/encrypted PDFs and geometric reading-order recovery are not supported by this small subset and must remain visibly unsupported, not guessed. This does not assert broad Adobe PDF compatibility or complete OCR reliability; substantive legislative pack ingestion requires source-specific verification. Revert this unit in a checked PR for rollback. AI-assisted review is not independent external certification.
