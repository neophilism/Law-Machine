# LM-017 classified evidence, assumptions and interpretation

This provider-free module maintains **different types** for exact source language, legal interpretation, empirical evidence, hypothetical assumptions and explicitly unknown facts. Numerical ranges retain units, finite bounds and limitations. Empirical operational delays and visitor assumptions cannot be marked as legal deadlines. Every operative rule must carry source-version-pinned references; every numerical forecast input must identify empirical evidence or a labeled assumption with compatible units. Invalid references, duplicates, unbounded collections and unsupported types fail closed.

Conflicting interpretations are retained as distinct records. A chosen resolution requires explicit, attributable acceptance and rationale; it does not destroy the alternative opinions. A pending or undecided conflict stays unresolved, and an unknown value never receives an implied default.

Tests: `tests/unit/evidence.test.ts` covers positive classified records; missing operative provenance; legal-vs-empirical classification; missing, foreign or mismatched forecast evidence; nonfinite/reversed units; competing interpretations and review dispositions; duplicate, malformed and injection-like records.

No automatic legal interpretation, legal deadline computation, external LLM, database or cloud credential is implemented here. Sources use the LM-003 versioned anchor contract; their actual authenticity, full bytes and current legal meaning remain governed by LM-004/LM-014 and later source-pack publishing. No real bill text is inferred.

Security and rollback: bounded validation without arbitrary code evaluation or remote fetching; no schema migrations. Revert this checked PR to remove the evidence module and disable downstream rule authoring that requires it. An AI-led code/security review is not an independent human audit.

Require final-head GitHub Actions `foundation` and `workspace` passes, including `pnpm check`, audit, build and browser tests, before merging. Record the final commit and run in PR body.
