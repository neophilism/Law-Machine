# LM-029 – Cancellable bounded browser-worker execution

Adds an explicit typed Worker protocol for fictional scheduler fixtures, a real dedicated worker with asynchronous 64-event progress batches, cancellation, runtime input caps, scheduler budget enforcement, and a browser client that fences every result to the latest run generation. Cancellation resolves the caller immediately; late messages from prior generations cannot mutate the new run. A crashing worker is terminated and recreated for the next request, without automatically duplicating old work. The fallback runs only up to 256 events and reports WORKER_UNAVAILABLE_BOUNDED_FALLBACK; larger requests fail explicitly.

A credential-free demonstration at /worker-preview runs 120-event and 5000-event fictional workloads, with progress, cancel and status controls. It is not a real law simulator. A published legal model and worker compiler bridge remain LM-030 and later work. Web Worker output is a projection of the existing deterministic scheduler, not a new legal transition engine.

Unit tests cover bounded requests, duplicate events, fallback trace identity, crash recovery and stale-generation isolation. Playwright in Chromium verifies a real worker run, responsive cancellation, a subsequent short run, and accessibility with axe. Required exact-head foundation/workspace CI includes pnpm check, audit, build and browser tests. No personal data, provider credentials, new database or production deployment is involved. Rollback by reviewed revert of this PR. No independent human audit is claimed.
