# LM-009 source import — first implementation slice

Initial provider-free text and Markdown adapters preserve an immutable copy of the exact input bytes, calculate SHA-256 identity and retain a separate UTF-8 extraction view. Numbering records describe detected headings and clauses without inventing legal semantics. Malformed UTF-8, binary content, unsafe names and overlong inputs fail closed.

This is not full LM-009 acceptance. Remaining work includes bounded DOCX archive extraction, table and hierarchy fidelity, malicious OOXML and archive expansion tests, and integrated source diagnostics. There are no external credentials or migrations; reverting this PR removes the provisional adapter. Do not claim a runnable legislative source pack from this milestone.
