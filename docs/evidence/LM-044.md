# LM-044 — quarantined source intake policy (CONTRIBUTING, incomplete)

This work defines a **provider-free preflight policy**, not an authenticated upload endpoint, private object store or remote fetcher. It is partial preparatory code for LM-044; LM-043 remains incomplete.

`packages/legislation/src/source-intake.ts` accepts syntactically valid scoped organization/document IDs, allowable extensions/content types, bounded input bytes, optional expected digest, and a deliberately private SHA-256-addressed quarantine key. It treats all input as untrusted. PDF and DOCX header checks are preliminary, not complete archive validation or antivirus scanning. For text formats it rejects malformed UTF-8, obvious HTML/script roots and binary NULs. Every accepted candidate is marked `quarantine-only`, `published:false`; this alone never makes source bytes public or eligible to support operative rules.

The separate official-source URL preflight restricts HTTPS to exact allowlisted official legislative publishers, rejects credentials, ports, fragments, queries, controls, encoded path traversal, raw traversal, lookalike domains, and private/address literals. It **does not** resolve DNS, check IP ranges, perform TLS handshakes, follow redirects or fetch content. A future isolated fetcher must pin official hostnames, validate every resolved address against private/reserved ranges, deny proxy/IP/redirect bypasses and enforce exact body/time limits. Do not turn this URL validation into a network fetch without those controls and source provenance review.

Unit tests cover scoped private candidate creation, byte digest mismatch, oversized and malformed files, preliminary format sanity and a hostile URL corpus. All examples are fictional; no private documents or credentials are committed.

**Missing LM-044 acceptance requirements:** completed LM-043 managed auth and sessions; isolated private durable storage and signed access controls; tenant-bound upload/download endpoints; quarantine scanning and bounded document parsing; explicit source review; resilient durable jobs; restart persistence; domain/redirect/DNS rebinding and network egress tests. This PR is listed as `contributingPrs` for LM-044, not `prs`. No cloud infrastructure, database schema or live author route is created. Rollback: revert this self-contained provider-free policy and tests. Production deployment, E2E and external security certification not claimed.
