# LM-024 branch exploration — first implementation slice

Adds pure three-valued exception branching. Unknown and absent facts are not silently false; they produce explicitly labeled finite hypothetical alternatives. Exceptions declare exactly which duty they modify and carry source references. Determinate conditions resolve to one branch; excessive alternatives return an explicit branch-limit diagnostic without choosing a default. Duplicate IDs, missing source references and cross-duty exceptions fail closed.

Additional tested features: nested exception dependency ordering, actor discretion as explicit alternative choices, and multiple competing source-linked interpretations retained rather than arbitrarily selected. Unsupported complexity is limited by explicit branch budgets. No independent human certification is asserted. Source-bound final CI must pass before merge. It depends on LM-023; merge only after that accepted dependency, source-bound CI and remaining acceptance work. No public legislative conclusions, credentials or migrations.
