# LM-014 dated baselines, source inventory and temporal applicability

The implementation pins agency/jurisdiction-scoped baseline records and exact source version identifiers, refuses missing or malformed evidence, and distinguishes proposals from enacted law. Time-dependent tests exercise prospective effective dates and unresolved transition periods. Unknown evidence remains explicitly unknown; no source gaps are filled by guessing.

## Bounded official excerpt inventory

`content/packs/federal-claims-excerpt-baseline.json` contains **two manually curated, dated short excerpts** from public federal government sources, with SHA-256 of the excerpt's exact UTF-8 bytes:

- **28 CFR 14.2(b)(1)**, Office of the Federal Register, eCFR displayed up to date **October 15, 2026**: https://www.ecfr.gov/current/title-28/chapter-I/part-14/section-14.2
- **28 USC 2675(a)**, Office of the Law Revision Counsel, preliminary Code source read as of **September 24, 2026**: https://uscode.house.gov/view.xhtml?req=%28title%3A28+section%3A2675+edition%3Aprelim%29

These support only a **narrow, cited inventory of the federal administrative-claims comparison area**. The excerpt hashes authenticate transcription *within this fixture* only. They **do not verify the original complete government file bytes or government publisher identity**; the verifier hard-codes `publisherAuthenticated: false` and `fullOriginalBytesVerified: false`, rejects forged origins and tampering, and does not fetch remote URLs. The dated fixture declares gaps for incomplete originals, agency-specific policies, relevant interpretations, electronic-filing authority, and missing proposed bill text. Accordingly, no public scenario may treat this inventory as an authoritative fully modeled legal baseline, calculate a live personal deadline, or assert the electronic filing proposal has been enacted.

## Verification and security

- Unit fixtures cover stage dates, explicit simulated proposal status, declared unknown baseline gaps, malformed and duplicate source references, transition consistency, excerpt tampering, origin spoofing and absent source records.
- Client and server import boundaries remain unchanged; pure package functions perform no untrusted code evaluation, network requests, credential or storage access.
- Required CI is `foundation` and `workspace` for the **exact final head**, including `pnpm check`, `pnpm audit`, `pnpm build` and Playwright browser/axe tests. Final SHA and CI evidence must be recorded before merge.
- Rollback is the reviewed revert of this unit, with LM-015 consolidation and dependent legislative features disabled or held for revalidation. No persistent migration or paid integration exists.
- Security review is AI-led. No independent human audit or certification is claimed.

**Source-scope restriction:** This unit delivers a traceable narrow excerpt snapshot and explicit missing-evidence state. A complete original-byte official baseline and the supplied electronic-filing bill remain required for the later initial content pack (LM-018) and production acceptance; neither is silently presumed here.
