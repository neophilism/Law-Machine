# LM-014: baseline snapshots, proposal status and temporal applicability

The library resolves dated baseline variants by jurisdiction/agency, explicit official-source snapshot records, staged effective dates, declared transition periods and the optional assumption of hypothetical enactment. Drafts, introduced bills and future legislative changes remain "not enacted" by default even when simulated dates exceed proposed effective dates. Enactment assumptions are explicitly labeled in the result and never change the recorded legislative status.

An official source snapshot must have a pinned digest, version label, official HTTPS origin, declared as-of date, citation and review verification. A vacant source inventory is not authoritative. Missing baseline material remains a structured gap rather than a guessed current-law rule, and different agency/jurisdiction scope produces an unresolved variant. Structural validation rejects bad dates, future snapshots, duplicate IDs, inconsistent transition intervals and unsupported sources.

Tests cover before/after transitions and enactment, missing source gaps, agency variants, temporal scope errors, invalid official URLs and duplicate law changes.

**Acceptance limitation**: The complete first electronic-filing bill text and verified official source bytes were not present in the source repository at this milestone. \`firstComparisonBaselineInventory()\` faithfully exposes an unverified baseline and missing version provenance for that area; it intentionally does NOT invent federal law. Official baseline content and its exact source digests must be attached and reviewed before claiming a completed official-source comparison pack in LM-018. Until this happens, this PR is an implementation of the temporal resolution core with explicitly incomplete actual-law coverage, not full product acceptance.

Security: no network or provider dependency, arbitrary file access, executable rule language, secret, external write or implicit publication. Rollback is a checked revert; no migrations. Required exact-head foundation/workspace checks and browser, type, audit and build gates. An AI-assisted review is not independent external certification.
