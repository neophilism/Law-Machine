# LM-014 temporal baseline implementation

Implements explicit dated jurisdiction/agency-scoped baseline records with source version/digest checks, declared coverage gaps, staged effective and transition dates, and proposal-versus-enacted distinctions. Hypothetical enactment requires an explicit option and is labeled in the result; a missing source baseline, missing effective date, or unresolved transition never produces a definitive legal outcome.

All records in tests are clearly fictional. The actual electronic-filing bill and official baseline sources have not been supplied; no actual law applicability is certified or invented. Integration with real source snapshots remains limited until those source bytes are available. No database migration, provider access, or credentials.

Tests: run pnpm check, pnpm audit, pnpm build, pnpm test:browser. Rollback: revert this PR after verifying dependent amendment features remain disabled.
