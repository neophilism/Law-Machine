# LM-013: exact source citation resolver and public inspector

Anchors contain the pinned version ID, source byte SHA-256, provision identity and exact text quote. A resolver never silently migrates an old anchor to the latest text: changed quotes become stale, missing source versions become unavailable and different source digests cause explicit mismatch. Displayed citations that resolve to multiple provisions remain ambiguous, not arbitrarily selected.

The public inspector shows an exact excerpt, diagnostic, pinned source reference, extraction quality, provision span and (only when independently supplied and allowlisted) an official HTTPS source link. It excludes private filenames, upload paths, original bytes, upstream API credentials, private release metadata and arbitrary URLs. PDF page anchors may be appended only to vetted official links. All content remains plain text and advisory to editorial review, not HTML or an operative rule.

Tests exercise old/new version history, changed quotes, digest mismatch, ambiguous numbering, absent versions, malformed refs, potential credential-leaking URLs and PDF page metadata. Release requires explicit publication authorization. Raw source-byte authenticity is separately enforced by LM-004 trusted manifests; a matching declared digest alone is not a government provenance certificate.

No storage/provider/secrets/deployment changes. Revert this PR for rollback. Required exact-head CI: foundation and workspace, including lint/types, unit tests, dependency audit, production build and browser tests. No independent external audit is claimed.
