# LM-007 coverage and capability work

Adds a pure reusable \`packages/legislation\` evaluator to model coverage declarations and host capability requirements separately. Version IDs and provision mappings are checked against the fully validated LM-003 public model. Explicit statuses and quantified unmapped counts prevent accidental silent coverage claims. A law's proposal status, baseline date and hypothetical label cannot be changed by visual-scene selection.

Safety review: no code evaluation, external services or automatic completion of unknown behavior. Any required unsupported operation, missing provision mapping, unknown version, unreviewed item or invalid factual baseline fails complete-execution reporting. The two partial-execution booleans represent modeling scope only, not permission to submit documents or legal correctness. The test data is invented toy law.

Unit tests cover supported and unavailable capabilities, unmapped/duplicate/unknown provision IDs, undeclared operations, invalid dates, unsupported/ambiguous explanations and scene-independent disclosure. Full source-bound CI still required. No external human certification is claimed.

No data migration. Rollback via a reviewed PR reverting this module/export and its tests. The LM-003 underlying model remains in place.
