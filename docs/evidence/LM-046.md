# LM-046 — PostgreSQL queue client (contributing; NOT accepted)

This change adds apps/jobs/src/postgres-lease-client.ts with a typed, server-only
adapter to the existing migration 0004 SQL functions. It provides transaction-local
organization scoping, durable enqueue/claim/heartbeat/checkpoint/complete/fail/
cancel/reap calls, and database-fenced compare-and-swap transitions. Lease fencing
is represented as bigint (not an unsafe JavaScript float). Each operation uses its
own short-lived transaction, always rolls back after errors and releases the client.

Adversarial provider-free tests cover malformed/foreign lease rejection, exact
fencing-token serialization above 2^53, SQL parameterization, tenant context,
idempotency arguments, data-bound checkpoint serialization and pooled rollback.
Existing PostgreSQL CI tests check actual row-level isolation, expired-lease
recovery and stale-worker rejection. The client deliberately imports no pg driver:
a privileged, server-constructed PgConnectionPool must be injected only after
the LM-043/LM-044 authentication, storage and deployment gates are satisfied.
The TypeScript marker serverVerified is NOT an authorization credential.

SECURITY REVIEW: Functions run SECURITY INVOKER with PUBLIC EXECUTE revoked.
Use a dedicated least-privilege worker DB role, with scope configured on the
server (never selected by a submitted org header/body). Database RLS and grants
remain authoritative; token string validation is defense in depth. A worker must
never publish external results before a successful fenced database transaction;
a CAS failure cannot retract side effects. No credential, private source, HTTP
endpoint, production database migration, publication or network call is added.
No worker service is started. This is NOT exactly-once external delivery.

CI acceptance for this contributing PR: exact-head foundation, workspace
(unit/type/lint/audit/build/browser) and postgres checks all successful.
The independent server process, real crash/restart E2E, storage integration,
fully authorized production worker role and idempotent immutable release
activation are still missing. LM-046 stays unaccepted.

Rollback: revert this isolated TypeScript adapter, tests and evidence. It adds
no schema changes or application route changes. No test-only migration inverse
should be used to roll back production data.
