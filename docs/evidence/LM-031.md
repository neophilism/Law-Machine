# LM-031 - planning-only source-unavailable preview (contributing work)

Implements a credential-free, responsive, static Next.js route to inspect the fourteen editorial electronic-filing scenario outlines from the incomplete LM-018 inventory. Every page prominently declares that the source bill, dated official baseline, exact legal citations, executable trace and enacted status are **unverified or unavailable**. It does not simulate real claims, accept filings or assign deadlines. No user account or private data is involved. Routes are marked `noindex,nofollow`, and unknown scenario IDs return 404.

This is NOT an accepted LM-031 public reading experience and must not enable a publishable pack or real legal assertions. The LM-031 dependency LM-018 is unsatisfied until authentic bill and baseline snapshots are available, so this is recorded only as a contributing PR. The future public pack landing page, real version selector, source explorer and accurate wrong-agency interactive journey remain outstanding. Rollback by reverting the route, link, CSS and tests; no database migrations or provider dependencies.
