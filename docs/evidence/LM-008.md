# LM-008 independent reference oracle (in progress)

This is intentionally invented toy law, not a description of any real filing rule. The oracle JSON was independently specified as three expected traces: a known Desk A to Desk B route (receive at tick 0, forward at tick 1, receive at tick 2); unknown destination (receive then unresolved, never pretend delivery); and absent initial filing (no events).

The small pure TypeScript interpreter is an explicit provisional fixture runner only, not the forthcoming law compiler or simulator. Each expected event has a versioned toy source reference. Automated tests compare the runner to the literal JSON oracle and enforce unknown handling and malformed fact rejection. Further required before milestone completion: browser/server parity on the same fixture, adversarial mutation tests, validator integration and reviewed scope/rollback notes. No services, secrets or migrations are involved.
