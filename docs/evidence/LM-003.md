# LM-003 domain contracts — implementation work in progress

This branch adds initial provider-independent typed entities, a strict schema-version tag and deterministic runtime validation of a bundled toy-law fixture. Versions, provisions, sources, roles, rules, assumptions, scenarios, releases and traces have distinct structural contracts. The validator rejects dangling references, cross-version source refs, unsupported version tags, negative/nonfinite quantities and duplicate IDs.

Not yet complete: deeper schema compatibility and source-digest relationship validation, nested cycle checks, declared actor/rule references throughout, and a full independently reviewed negative corpus. Do not treat this branch as LM-003 acceptance merely because an early CI run passes. No real legal text is included; examples are fictional.

Run `pnpm check`, `pnpm build`, and browser tests on the exact PR head. Rollback requires reverting this branch; there is no migration or provider configuration.
