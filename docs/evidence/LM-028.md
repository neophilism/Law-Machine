# LM-028 – Source-linked explanations and causal inspection

Adds provider-free, deterministic explanation projections from authored simulation event records and pinned source inventories. Outcomes show applied rule, causal parents, exact quoted provision, predicate truth values, exceptions, classified evidence and explicitly unresolved alternative interpretations. The causal graph is iteratively checked for cycles, missing parents, stale source quotes, mismatched digests, absent rules and references. Unknown predicates, outcomes and alternative branches receive an unresolved state and a fixed non-definitive public text; the renderer cannot invent a legal conclusion.

Public explanations use only allowlisted authored text tokens and field substitutions. No generative model, arbitrary template evaluation, JavaScript execution, private documents or provider calls occur. Treat publicText as plain text and never render using unescaped HTML. Source strings are not proof of publication or legal correctness: original source-byte and release verification remain mandatory upstream (LM-004/013).

Unit tests use an explicitly fictional law and verify causal references, unknown outcomes, missing/mutated sources, malformed annotations, cycles and bounded graph traversal. No production content pack is claimed. Existing browser accessibility suite remains required; additional actual-published-pack end-to-end tests depend on LM-018/030. There are no secrets, migrations or cloud dependencies. Required GitHub foundation/workspace checks must pass at current head. Rollback by reviewed revert. No independent human certification is claimed.
