# LM-026 replay streams

Provider-free deterministic xorshift32 random streams, scoped by stable names, canonical run identity including engine and calendar versions, bounded replay import/export, explicit fixed decimal rounding and checkpoints. The algorithm is noncryptographic and must never be used for secrets. Unit tests cover deterministic streams, independence across subsystems, version-sensitive identity, serialization and malformed inputs. Browser/Node parity and independent reference vectors remain to complete acceptance. No deployment or migration. Rollback: revert this milestone.
