# LM-021 — deterministic scheduler implementation

Provider-free, bounded discrete-event scheduling with stable (tick, identifier) ordering, typed causal IDs, provenance-bearing events, immutable trace snapshots, explicit pause/step/resume, cancellation, repeated-tick detection, event budget and fail-closed malformed-event rejection. No wall clock is accessed. Unit tests cover deterministic traces under changed insertion order, pausing, same-tick loops, budgets and causally scheduled work.

This engine schedules declared events but does not itself derive legal facts or legal outcomes. Rule compilation and event provenance validation remain separate; LM-023 introduces duties and rights. Security constraints: source references are mandatory, inputs and budgets are bounded, no arbitrary code string evaluation, provider networking or persistence. Callbacks are trusted application code, never imported legal source content. No migration; rollback via a checked revert of this PR.
