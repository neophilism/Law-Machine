# ADR-0003: Source-grounded simulation and explicit limits

Status: accepted design.

Sources, provision trees, interpretations, executable rules, releases and scenes have separate versioned identities. Preserve original bytes and exact citations. A proposal never becomes enacted law by default. Baselines are dated and jurisdiction-scoped.

Legal force and behavior are distinct: a two-day routing duty can coexist with five-day performance and a recorded breach. Permissions do not compel actions. Unknown facts remain unknown; disputed interpretation produces declared alternatives or a limited result.

Run identity includes release digest, normalized scenario inputs, behavior assumptions, seed, engine/calendar versions and numeric rules. Use deterministic clocks and typed quantities; retain compatible release engines. Visual playback cannot change the trace.

Public input is structured hypothetical data. No real filing intake, government receipts, merits decisions or authoritative personal deadlines. Every public outcome retains provenance and qualifications. The first bill's full text must be sourced in LM-018; architecture examples are not substitute legislative text.

Ask Bill can consume the future SDK and semantic focus targets. Character, chat, voice and 3D work are outside this 60-unit Law Machine plan.
